➕ Ajouter un style

📋 Importer depuis Internet

Colle ici le texte copié tel quel depuis un site d'accords : soit les accords sur une ligne au-dessus des paroles, soit entre crochets comme [Sol] ou [G]. L'appli les replace automatiquement au-dessus de la bonne lettre ou du bon mot, exactement comme les notes ajoutées à la main.

📋 Importer des notes de jeu

Colle ici ce que tu as trouvé sur internet (par exemple « Intro : … », « Couplet : … », « Refrain : … », « Solo : … »). L'appli reconnaît ces mots et range le texte tout seul dans la bonne case.

⬇️ Exporter des medleys

Choisis les medleys à exporter. Le fichier inclut aussi les chansons qu'ils utilisent, pour qu'ils s'importent correctement sur un autre appareil.

⬆️ Importer des medleys
